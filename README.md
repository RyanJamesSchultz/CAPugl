# CAPugl

I present a Matlab-based enviroment, CAPugl that uses CAP-tests to infer if a maximum magnitude is bounding a catalogue of earthquakes.  This repository is related to a study about the same topic [Schultz et al., 2026].  This repository contains programs, scripts, and data to recreate figures and results of the prior study.  The core tools developed are KS_dM_test.m, M2fit.m, and EnsembleW.m.  See also my prior GitHub repositories for required routines (e.g., Bval.m).

Note that the CAP-tests have been improved upon by future work. See my CAP2 repository for the improved versions of the CAP-tests.

References: 
            
            R. Schultz, L. Villiger, V. Gischig, & S. Wiemer (2026)
            Interpreting the cause of bound earthquakes at underground injection experiments
            Solid Earth, 17(4), 617-642.
            doi: 10.5194/se-17-617-2026.
